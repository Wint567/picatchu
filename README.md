# Picatchu — Product Landing Page

A responsive product website with feature sections, FAQ interactions, a contact modal and separate policy pages.

**Stack:** HTML · CSS · Tailwind CSS via CDN · JavaScript

## Features

- Responsive navigation and illustrated product sections.
- Expandable FAQ items.
- Contact modal with custom selection controls and Escape dismissal.
- Separate privacy policy and terms page layouts.

## Run locally

Open `index.html` in a browser, or use a static web server. Internet access is required for external CDN and font resources.

## Structure

- `index.html` — landing page.
- `privacyPolicy.html`, `termsAndConditions.html` — supporting pages.
- `css/style.css` — custom styling.
- `js/main.js`, `js/privacyAndTerms.js` — page interactions.
- `public/` — illustrations and icons.

## Scope

A frontend interface implementation. Product services and a contact-form backend are outside this repository.
